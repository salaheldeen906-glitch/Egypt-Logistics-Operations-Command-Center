## التطوير

المتطلبات: Node.js 22.13 أو أحدث، وpnpm 11.25.0 بحسب `package.json`.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

البناء وفحص الأنواع:

```sh
pnpm build
pnpm exec tsc --noEmit --incremental false
```

اختبارات نموذجية:

```sh
node scripts/test-domain.mjs
node scripts/test-external-transport.mjs
node scripts/test-external-transport-access.mjs
node scripts/test-external-transport-reports.mjs
node scripts/test-external-review.mjs
```

بعد البناء، يمكن تشغيل اختبار API المعزول:

```sh
node scripts/test-external-api.mjs
```

اختبارات API تستخدم Worker وD1 وR2 محلية بهويات اختبار محاكاة، ولا تثبت تسجيل دخول حسابات حقيقية. نتائج الإصدار المسجلة موجودة في وثيقة الإصدار؛ لم يُعَد اختبار منصة استضافة أخرى أثناء نقل المستودع.

## التخزين والدخول والنشر

- التقنية: React/TypeScript، Vinext/Vite، Cloudflare Workers، D1، R2.
- `.openai/hosting.json` يحفظ معرّف الموقع وأسماء ربط التخزين؛ لا يحتوي أسرار التشغيل.
- إعدادات الدخول والأسرار وربط قاعدة البيانات والمرفقات تُدار في بيئة التشغيل الحالية، ولا تنتقل تلقائيًا مع GitHub.
- رفع هذا المستودع لا يغيّر الموقع المنشور ولا يرحّل بياناته، ولا يكفي تشغيل GitHub Pages لتشغيل الخادم وقاعدة البيانات.
- لا تثق في ترويسات هوية يرسلها الزائر مباشرة. نشر التطبيق خارج بيئته الحالية يحتاج إعداد حدود الهوية والتخزين والتحقق منها.
- لا تُشغّل ترحيلات أو استعادة قاعدة البيانات على بيانات فعلية باعتبارها خطوة لازمة لمجرد تنزيل الكود.
