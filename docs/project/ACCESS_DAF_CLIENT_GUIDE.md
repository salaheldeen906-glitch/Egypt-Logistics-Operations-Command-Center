# دليل العميل — دخول DAF وإدارة فريقك

1. افتح الرابط الذي سلّمه لك المسؤول، واكتب اسم الدخول أو البريد وكلمة المرور. احتفظ ببياناتك في وسيلة خاصة.
2. بعد الدخول تظهر الشاشات والبيانات المسموحة لحسابك. تغيير المشروع لا يمنح صلاحية إضافية.
3. إذا كنت مسؤول فريق مخولًا، افتح «المستخدمون والصلاحيات». يمكنك إضافة حسابات وتعديلها داخل مدة ونطاق وسقف تفويضك. بعض الصلاحيات قد تحتاج الرجوع للمسؤول.
4. في تعديل الحساب، ترك كلمة المرور فارغة يبقيها. تعيين بديلة أو تغيير الصلاحيات ينهي جلسات الحساب القديمة؛ يلزم دخول جديد.
5. «افتراضي الدور» يحتفظ بصلاحيات الدور المعتادة. «منع» يغلب السماح؛ السماح بإجراء لا يتيح شاشة محظورة أو تجاوز خطوة تشغيل معتمدة.
6. يمكن إظهار/إخفاء تفاصيل الصلاحيات والبحث باسم الشاشة أو الإجراء. إغلاق التفاصيل لا يحذف بيانات.
7. عند انتهاء الوصول أو إيقافه، تواصل مع المسؤول. البيانات التشغيلية والمهام لا تُحذف تلقائيًا ولا تُؤكد نيابة عن صاحبها.
8. استخدم «تسجيل الخروج» عند الانتهاء، خصوصًا على الأجهزة المشتركة. لا تشارك كلمة المرور أو ملفات المراجعة الداخلية.
